# استوديو المحتوى

تطبيق ويب عربي متعدد البراندات لصناعة حملات سوشيال ميديا جاهزة للنشر باستخدام Gemini وNano Banana وVeo.

## المزايا

- إدارة البراندات وهويتها البصرية والجمهور ونبرة الصوت ومصادر المعرفة وروابط Google Drive.
- إدارة الشخصيات الإعلانية وصورها والبرسونا والمظهر والقيود والبراندات المرتبطة.
- رفع ملفات `SKILL.md` أو تحريرها داخل التطبيق واستخدامها كقواعد للتوليد.
- إنشاء صورة، كاروسيل، فيديو أو نص لمنصات إنستجرام وفيسبوك وX ولينكدإن وتيك توك.
- توليد فكرة إبداعية، برومبت بصري، نص التصميم، وصف بديل، تدقيق هوية ونسخة مخصصة لكل منصة.
- تنزيل التصميم كصورة PNG، نسخ المنشور، وحفظ كل الحملات في المكتبة.
- وضع عرض كامل بدون مفتاح API، وفصل بيانات المستخدمين مع D1 وتخزين الملفات في R2.

## التقنية

React 19، TypeScript، Vinext، Cloudflare Workers، D1، R2، Drizzle ORM، Gemini Interactions API، Gemini 3.1 Flash Image وVeo 3.1 Lite.

## التشغيل المحلي

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Node.js 22.13 أو أحدث مطلوب.

## إعداد الذكاء الاصطناعي

أضف `GEMINI_API_KEY` كسر في بيئة الخادم. المتغيرات الاختيارية:

```env
GEMINI_TEXT_MODEL=gemini-3.7-flash
GEMINI_IMAGE_MODEL=gemini-3.1-flash-image
GEMINI_VIDEO_MODEL=veo-3.1-lite-generate-preview
```

لا تضع المفتاح في كود الواجهة أو المستودع. جميع طلبات التوليد خادمية.

## التحقق

```bash

```

## Google Drive

يقبل التطبيق روابط Drive ضمن مصادر البراند. الروابط الخاصة تظل خاضعة لصلاحيات Google؛ التطبيق لا يجعلها عامة ولا يتجاوز صلاحيات الحساب. يمكن رفع الملفات والصور مباشرة إلى مساحة التخزين الخاصة بالتطبيق.

## هيكل المشروع

- `app/`: الواجهات ومسارات API.
- `lib/server-ai.ts`: التخطيط وتوليد الصور والفيديو.
- `lib/server-data.ts`: عمليات D1.
- `lib/server-storage.ts`: رفع الملفات والأصول المولدة.
- `db/schema.ts`: مخطط البيانات.
- `drizzle/`: ترحيل قاعدة البيانات.
